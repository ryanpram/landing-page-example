This is a test page to verify cross-page tracking and session persistence with Cekat Track SDK.

Our Mission

We are committed to providing high-quality products and exceptional customer service. This test page helps verify that the Cekat Track SDK properly tracks user journeys across multiple pages.

When you navigate between pages, the SDK should maintain the same visitor ID and track all page views in a single session.

What We're Testing

Session Persistence: Your visitor ID should remain the same across all pages.

Page View Tracking: Each page load should send a tracking event.

Referrer Tracking: The SDK tracks which page you came from.

Cross-page Journey: All events are linked to the same visitor ID, creating a complete journey map.
